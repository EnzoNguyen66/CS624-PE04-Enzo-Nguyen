# CS624-PE04-Enzo-Nguyen

The application takes in information about an individual including an image, name, job title, and a brief introduction. In Part 1, the application displays a single Profile Card. In Part 2, it utilizes data for six individuals to generate six Profile Cards.

The application uses React Native for the user interface, with "StyleSheet" applied to style the cards. In Part 1, the information is presented within a card centered on the screen. In Part 2, the application leverages a dataset and the "map()" method to render six cards, with Flexbox used to arrange them into rows and columns. When a user taps a card, the application updates its state to either enlarge or shrink that card.

In Part 1, the screen displays a single, detailed Profile Card. In Part 2, the screen presents six Profile Cards in a thumbnail format. Users can tap on any individual card to view an enlarged version of the information, and tap it again to return it to its smaller size.
